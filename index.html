About

NEXORA is a modern messaging, social and AI assistant application. Built with a focus on clean design, privacy controls and a powerful built-in AI.

Features

  • Private & group messaging
  • Stories (24-hour)
  • User discovery
  • NEXORA AI assistant (Coming Soon)
  • Voice call UI
  • Data Saver controls
  • Private Command Center

Real AI (Optional)

NEXORA AI currently runs in local mode.

You can connect a free real AI model using Groq + Cloudflare Workers.
Full instructions are in the backend-stub folder of the project.

Development

Frontend built with HTML, CSS and JavaScript.
Designed for Android and iPhone.
Runs fully on-device. Real AI is optional and free to enable.
